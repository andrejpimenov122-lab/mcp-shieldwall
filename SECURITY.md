# Security Policy

## Reporting a Vulnerability

If you discover a security issue, bypass, or false-negative in **MCP Shieldwall**, please do **not** open a public issue with live exploit payloads against third-party servers.

- Email: `andreyy.2200223@gmail.com`
- Include a minimal reproducible MCP tool manifest or JSON-RPC snippet and expected vs. actual behavior.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.2.x   | Yes       |
| 0.1.x   | Security fixes backported where feasible |
